GEARS LATTICE: An interactive systems diagram modeling how coercive systems lock into self-reinforcement — four coupled variables (control, selection, information flow, feedback cost) rendered as an interlocking lattice, with motion used to encode the causal loop rather than decorate it. 



[**View the live diagram →**](https://JV7T9.github.io/gears-lattice/) screenshot.png



WHAT THIS IS: A descriptive model, not a proof: click any node to see how it drives the next one in the loop. The two faint outward lines marked RUPTURE? and FRACTURE? are deliberately left unresolved — the model explains lock-in well, it doesn't yet explain what breaks it. That gap is shown on purpose rather than smoothed over.



THE FOUR GEARS: 

|1. Gears -->Concentration of resources, force, law, and infrastructure 
|2. Traits -->Which traits a system selects for and against 
|3. Comms -->Control of information flow and shared legibility 
|4. EI / Moral -->The emotional and moral cost of seeing the system clearly



Each feeds the next in a clockwise loop; dashed cross-links show the secondary couplings that make it a lattice rather than a simple chain.



BUILT WITH: Plain HTML, CSS, and vanilla JS — no framework, no build step. SVG for the diagram, prefers-reduced-motion respected, keyboard-accessible nodes.



STATUS: A conceptual sketch, open to revision. Notably missing: exit/rupture conditions (elite-coalition breakdown, external shock, economic collapse) — flagged in the diagram itself rather than modeled.
